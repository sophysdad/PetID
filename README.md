# MoosePond Designs — Pet ID Tags

This repository hosts the public pages for MoosePond Designs' NFC/QR Pet ID tags.

Each page is a self-contained HTML file named with a random unguessable slug (e.g. `4ba9fb7e97840b2e.html`) so it can only be found by scanning the physical tag. There is no index or listing of tags on this site.

Private customer/order records are kept separately and are not stored in this repository.
